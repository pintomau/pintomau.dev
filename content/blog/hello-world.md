Hello, internet. This is my first blog post.

I'm Mauro Pinto, a software engineer who's been meaning to start a blog for longer than I'd like to admit. Here it is, finally.

## What to Expect

I plan to write about:

- **Code** — Technical deep dives, architecture decisions, and things I've learned the hard way.
- **Tooling** — The tools, workflows, and setups that make me more productive (or at least feel that way).
- **Craft** — The softer side of engineering: how we think about code, how we collaborate, and how we build things that last.

## Why a Blog?

A few reasons:

1. **Writing clarifies thinking.** If I can't explain something in writing, I probably don't understand it well enough.
2. **Future me will thank past me.** Blog posts are great bookmarks for things I've learned.
3. **Sharing is good.** If even one person finds something useful here, it's worth it.

## The Stack

This blog is built with [Zola](https://www.getzola.org/), a fast static site generator written in Rust. It uses the [Terminus](https://github.com/ebkalderon/terminus) theme, is hosted on GitHub Pages, and served via Cloudflare. More on this in a future post.
